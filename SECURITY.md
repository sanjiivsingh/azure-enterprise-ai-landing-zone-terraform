# Security Policy

## Reporting a Vulnerability
Please report security vulnerabilities responsibly via:
* **GitHub Private Security Advisory:** [Report an advisory](https://github.com/sanjiivsingh/azure-enterprise-ai-landing-zone-terraform/security/advisories/new)
* **Direct Contact:** [https://github.com/sanjiivsingh](https://github.com/sanjiivsingh)

We acknowledge all reports within 48 hours.
